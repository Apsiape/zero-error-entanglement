\section{Reproducibility and claim attribution}\label{sec:repro}
The accompanying portable verification directory contains finite matrix checks, explicit pass/fail assertions, and exact general-bridge checks. Run \texttt{python run\_all.py} after installing the packages in \texttt{requirements.txt}. Each invocation writes to a fresh output directory. Floating-point matrix checks use explicit tolerances; the bridge and Catalan constants are checked symbolically. The runner reports a failure if any assertion fails. The recorded results, dependency versions and source hashes accompany the bundle.

The magic-square graph has classical independence number five and a six-message entangled code. The flagged-magic-square graph has fifty vertices, classical independence number nine and a ten-message entangled code. The reverse map is also tested after a noncommutative row-and-column scrambling. These examples verify the implementation of the finite correspondence already proved in \cite{Mancinska}; they are not novelty claims. The naive $D^2$ forward marginal is tested as a negative control.

The exact script checks $4n+1$, $6n+1$, $\Omega_n$, normalized scaffold weights, source/far mass ratios, convergence and criticality of the amplitude series, the five/eight constants, the five-bridge code entropy, the squared Catalan entropy, and all identities in \eqref{eq:Catnumbers}. The infinite entropy conclusion uses Catalan asymptotics in the proof, not a finite partial entropy sum.
